# Разбиение массива

Дан массив из `n` чисел. Без использования дополнительной памяти (вспомогательные массивы и другие контейнеры)
поменять местами элементы таким образом, чтобы сначала шли отрицательные элементы, затем нулевые, потом положительные элементы.
Взаимное расположение элементов в своих категориях должно остаться неизменным.
