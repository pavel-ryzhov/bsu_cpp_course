# Умножение матриц

Даны две матрицы (`std::vector<std::vector<int32_t>>`) размера $n \times k$ и $k \times m$. Найти их [произведение](https://ru.wikipedia.org/wiki/Умножение_матриц).
Гарантируется, что все элементы итоговой матрицы помещаются в int32_t.

Примечание:
* Подумайте, что такое пустая матрица.
