# Работа с изображениями
В этом задании вам предстоит поработать с изображениями, представленными в виде двумерных матриц: читать их из файла, модифицировать и записывать в файл.

Любое изображение может быть представлено в виде прямоугольной матрицы цветов пикселей. Если изображение черно-белое, то в качестве цвета достаточно использовать одно число от 0 до 255 — "яркость" пикселя.
Цветные изображения разбивают на несколько каналов, соответствующих разным цветам. Чаще всего используется аддитивная палитра "RGB" с тремя основными цветами — красный, зеленый и синий. Таким образом, каждый пиксель представляется в виде трех чисел от 0 до 255 — яркости каждого из компонент цвета. Например, `(255, 0, 0)` — красный цвет, `(0, 0, 0)` — черный, а `(255, 255, 255)` — белый.

Вам предлагается реализовать шаблон класса `Matrix<T>`, представляющий матрицу с элементами типа `T`, а затем использовать `Matrix<uint8_t>` для работы с черно-белыми изображениями и `Matrix<RGB>` — для работы с цветными.

## Задание 1. Матрица
Реализуйте шаблон класса `Matrix<T>` для работы с двумерными массивами (матрицами). Для хранения элементов используйте `std::vector<std::vector<T>>`.

Реализуйте следующие методы:
- Конструктор, принимающий числа `size_t n`, `size_t m`, `const T& value` и создающий матрицу `n`×`m` из одинаковых чисел `value`. Если `value` не задан (конструктор вызывается с двумя аргументами), используйте конструктор `T` по умолчанию.
- Конструктор, принимающий число `size_t n` и создающий квадратную матрицу `n`×`n` из одинаковых элементов — значений типа `T` по умолчанию.
- Конструктор, принимающий `std::vector<std::vector<T>>` и создающий матрицу из элементов переданного массива. Вы должны убедиться, что все строки имеют одинаковую длину и, если это не так, бросить соответствующее исключение.
- Конструктор копирования.
- Статический метод `Identity(size_t n)`, создающий единичную матрицу размера `n`. Можете считать, что число `1` всегда преобразуется к типу `T`.
- Метод `size_t Rows() const`, возвращающий количество строк.
- Метод `size_t Columns() const`, возвращающий количество столбцов.
- Метод `const std::vector<std::vector<T>>& Data() const`, который возвращает ссылку на элементы матрицы. Обратите внимание, что этот метод нужен для упрощения тестирования вашего класса, и в реальном коде использовался бы другой подход.
- Оператор `(size_t i, size_t j)`, возвращающий элемент матрицы, и работающий таким образом, чтобы выражение `a(i, j) = x` записывало значение `x` в ячейку матрицы `a` с индексами `i`,`j`. Если элемента не существует, метод должен выбросить исключение.
- Метод `Transpose`, создающий новую матрицу, полученную [транспонированием](https://ru.wikipedia.org/wiki/Транспонированная_матрица) данной. Обратите внимание, что если матрица была размера `n`×`m`, то станет `m`×`n`.
- Бинарные операторы `+`, `-`, `*`, `+=`, `-=`, `*=`, выполняющие соответствующие операции с матрицами. Оператор `*` должен вычислять [матричное произведение](https://ru.wikipedia.org/wiki/Умножение_матриц). Обратите внимание, что легче и эффективнее реализовать оператор `+=`, а `+` выразить через него (используйте копирование). А вот с умножением ситуация ровно противоположная.
- Операторы `==` и `!=`, выполняющие поэлементное сравнение матриц.

Также реализуйте свободную функцию `Transpose` от одного аргумента, аналогичную методу класса.

## Задание 2. Изображения
Определим тип `Image` как `Matrix<RGB>`, где `RGB` — простая структура, содержащая однобайтовые поля `r`, `g` и `b`.

Реализуйте следующие функции преобразования таких изображений. См. тесты для более детального понимания.

#### `FlipHorizontally`
Создает новую матрицу, полученную горизонтальным отражением данной.

#### `ToGray`
Функция принимает цветное изображение, а возвращает — черно-белое. Для получения яркости пикселя используйте среднее арифметическое яркостей каналов: `(r + g + b) / 3`.

#### `Blend`
Функция принимает два изображения одинакового размера и создаёт новое, где цвет каждого пикселя получен смешиванием цветов соответствующих пикселей первого и второго изображения с коэффициентом $\alpha$, пропорциональным горизонтальной позиции пикселя на изображении. Иными словами, изображение должно "перетекать" из первого во второе слева направо.

#### `RotateClockwise`
Создает новую матрицу, полученную поворотом данной на 90 градусов по часовой стрелке.
*Подсказка*: разложите операцию поворота на две более простые операции.

#### `MixChannels`
Принимает изображение и дробную матрицу `A` размера 3×3 — преобразование каналов пикселя. Функция должна применить данное преобразование к каждому пикселю изображения, заменяя $[r, g, b]$ на $A \cdot [r, g, b]^T$, и вернуть получившуюся матрицу. Если значение в канале получается меньше 0 или больше 255, заменить его на граничное.

Например, матрица со всеми элементами равными $\frac{1}{3}$ превратит изображение в черно-белое.

#### *`Convolve`
Принимает изображение и дробную матрицу произвольного размера и выполняет операцию [свёртки](https://en.wikipedia.org/wiki/Kernel_(image_processing)#Convolution) каждого канала (цвета) независимо от других. Размер результата свёртки матрицы размера `n`×`m` с ядром размера `a`×`b` должен быть `(n-a+1)`×`(m-b+1)`, то есть ядро прикладывается без выхода за края изображения. Если значение в канале получается меньше 0 или больше 255, заменить его на граничное.
