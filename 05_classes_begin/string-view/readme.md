# String View

Реализуйте класс `StringView`, упрощенный аналог [std::string_view](http://en.cppreference.com/w/cpp/string/basic_string_view).

Данный класс, в отличие от `std::string`, не владеет строкой, но хранит указатель на ее начало и размер. Это позволяет создавать
"копии" строк и выделять подстроки практически бесплатно. Однако стоит понимать, что поскольку `StringView` не владеет строкой, а лишь
наблюдает за ней, при изменении этой строки он "увидит" эти изменения. При этом сам класс StringView не может изменять строку, за которой наблюдает.

Вам не предоставляется интерфейс класса, вы должны написать его полностью сами. Реализуйте следующее:

* Дефолтный конструктор
* Конструктор копирования
* Конструкторы(два), принимающий `const std::string&`, размер подстроки (по умолчанию `data.size()`). Первый принимает только строку, второй строку и размер.
* Конструкторы(два), принимающий `const char*` --- указатель на некоторую С-строку. Используйте [strlen](http://en.cppreference.com/w/cpp/string/byte/strlen), чтобы узнать ее длину, позицию начала подстроки (по умолчанию весь размер). Первый принимает только указатель строки, второй указатель и размер.
* Шаблонный конструктор, принмающий два `first` и `last` типа `std::random_access_iterator`
* Удалите конструктор от `std::nullptr_t`
* Оператор = принимающий `const StringView&`
* Константный оператор `[i]`, с помощью которого можно узнать символ в позиции `i`. Так как возможности изменять строку через объект класса `StringView` нет, то неконстантный оператор `[i]` не нужен.
* Константный метод `Substr`, аналогично std-шному.
Первым аргументом с какой позиции(по умолчанию `0`), вторым аргументом сколько элементов(по умолчанию `std::string::npos`)
[std::string::npos](http://en.cppreference.com/w/cpp/string/basic_string/npos)).
* Константный метод `Data`, возвращающий указатель на начало наблюдаемой строки.
* Константный метод `Size`, возвращающий длину наблюдаемой строки.
* Константный метод `At`, с помощью которого можно узнать символ в позиции `i`. Должен бросать
  исключение `std::out_of_range`, если выходит за границы
* Константный метод `Empty` -- как у `std::string_view`.
* Константный метод `Front` -- как у `std::string_view`.
* Константный метод `Back` -- как у `std::string_view`.

В тестах можно посмотреть примеры использования класса.

### Примечания

* Передача строки по значению в конструкторах была бы плохой идеей.
* Запрещено использование [std::string_view](http://en.cppreference.com/w/cpp/string/basic_string_view).
* Вам разрешено не помечать конструкторы словом
  [explicit](https://en.cppreference.com/w/cpp/language/explicit) , для этого используйте `// NOLINT(google-explicit-constructor,hicpp-explicit-conversions)`. Для того, чтобы наша реализация была максимально похожна на ерализацию std.
* Также в Substr можно использовать дефолтные значения, для этого используйте `// NOLINT(fuchsia-default-arguments-declarations)` это отключит проверку `clang-tidy`
* [nodiscard](https://en.cppreference.com/w/cpp/language/attributes/nodiscard)
