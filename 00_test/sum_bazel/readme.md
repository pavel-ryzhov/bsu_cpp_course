# Сложение чисел

Эта задача предназначена для знакомства с тестирующей системой. Вам предстоит реализовать функцию `Sum`, которая складывает 2 числа, в файле `sum.h`. Перед тем как приступить настройте окружение согласно [инструкции](../../docs/SETUP.md).

В этой версии задачи вам также нужно доказать корректную установку, приложив вывод следующей команды:

```bash
bazel query 'deps(//00_test/sum_bazel:all)' 2>/dev/null | grep -v "@" | sort | md5sum | cut -c -15
```

## Структура задачи

В каждой задаче обычно есть как минимум 3 файла:

* `BUILD` --- bazel-файл для сборки задачи.
* `test.cpp` --- сами тесты для задачи.
* `*.h` --- некоторый .h файл, в котором вы должны реализовать то, что требуется в условии задачи (в данном случае `sum.h`).

Вам разрешено изменять только файлы, содержащие решение задачи, изменения в иных файлах будут игнорироваться при тестировании вашего решения.
Когда вы делаете посылку, система запускает `test.cpp`, и в случае успешного завершения
задача вам засчитывается.

Обратите внимание, что в некоторых задачах `test.cpp` может либо вообще не содержать тестов, либо содержать не все тесты, которые будут на сервере --- об этом всегда сообщается в условии задачи.
В этом случае вы сами должны написать тесты и протестировать всю реализованную функциональность.

## Сборка

Для корректной сборки необходим `g++` версии не ниже 13 или `clang++` версии не ниже 17.0.

Для новичков мы рекомендуем использовать Visual Studio Code. Сборка с его использованием разобрана в инструкции на странице курса. Здесь приведены инструкции для использования из консоли.

```bash
# Запустим сборку и запуск всех тестов задачи 00_test/sum
bazel test //00_test/sum_bazel:all
# Или:
cd 00_test/sum_bazel
bazel test :all
```

Если вы хотите только скомпилировать решение, но не запускать тесты, используйте команду `build`:

```bash
bazel build //00_test/sum_bazel:all
```

Если хотите видеть вывод падающих тестов:

```bash
# Находясь в папке с задачей
bazel test :all --test_output=errors
```

Если хотите сделать это поведением по умолчанию, можете создать файл `~/.bazelrc` со следующим содержимым:

```bash
test --test_output=errors
```

Все задачи включены в один проект, поэтому если вы попытаетесь собрать проект целиком, могут возникнуть ошибки. Поэтому при сборке нужно указывать конкретную задачу, которая вам нужна.

Обратите внимание, что помимо этого на сервере также осуществляется тестирование с включенным санитайзером(Asan), которые проверяют наличие неопределенного поведения и некорректной работы с памятью
в программе. Осуществить такую сборку просто:

```bash
bazel test //00_test/sum_bazel:all --config=asan
```

Если вы реализуете решение в этой задаче просто как `a + b` (без приведения к `int64_t`), то тесты в asan-сборке должны упасть с соответствующим сообщением о переполнении.

## Примечания

Обратите внимание, что в реальности в .h файлах не пишутся реализации функций и классов, но для простоты в задачах первых семинаров вам нужно будет писать реализации в .h файлах.
