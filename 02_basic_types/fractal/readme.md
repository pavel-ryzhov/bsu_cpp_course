# Загадочная функция

Вам дана функция, генерирующая последовательность строк, являющихся двоичным представлением некоторых чисел $a_i$.
Ваша задача — найти рекуррентную функцию $f(n)$, производящую эту последовательность преобразованием $a_i = f(a_{i-1})$.

Вы должны пройти тесты, сделав изменения **только** в файле `function.h`.
