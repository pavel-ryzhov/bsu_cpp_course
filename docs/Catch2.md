<details><summary><b>Как использовать фильтры, чтобы запустить только нужный мне тест на catch2?</b></summary>

Чтобы запустить только нужный вам тест в Catch2 на C++, вы можете использовать фильтры на основе имени теста или тегов, которые вы присваиваете тестам. Вот как это сделать:

**1. Использование имени теста**

Если вы знаете точное имя теста, вы можете передать его в качестве аргумента при запуске вашего тестового исполняемого файла:

```shell
bazel run //<путь_до_таргета> -- "ИмяВашегоТеста"
```

Это запустит только тот тест, имя которого совпадает с "ИмяВашегоТеста".

**2. Использование шаблонов (wildcards)**

Вы можете использовать символы подстановки, чтобы запустить группу тестов, имена которых соответствуют определенному шаблону:

- Запустить все тесты, начинающиеся с "MyTest":

```shell
  bazel run //<путь_до_таргета> -- "MyTest*"
```

- Запустить все тесты, содержащие слово "Error":

```shell
  bazel run //<путь_до_таргета> -- "*Error*"
```

**3. Использование тегов**

Catch2 позволяет присваивать тег(и) каждому тесту, что удобно для организации и фильтрации тестов.

*Пример присвоения тега тесту:*

```cpp
TEST_CASE("Проверка факториала", "[factorial]") {
    // код теста
}
```

Чтобы запустить все тесты с тегом [factorial], используйте:

```shell
./ваш_тестовый_исполняемый_файл "[factorial]"
```

**4. Комбинирование тегов и шаблонов**

Вы можете комбинировать фильтры по имени и тегам, а также использовать логические операторы ~ (НЕ), * (И), , (ИЛИ):

- Запустить тесты с тегом [math], но исключить те, которые помечены тегом [slow]:

```shell
  bazel run //<путь_до_таргета> -- "[math]~[slow]"
```

- Запустить тесты, имя которых начинается с "Calc" и они помечены тегом [important]:

```shell
  bazel run //<путь_до_таргета> -- "Calc*" "[important]"
```

**5. Использование командных опций**

Catch2 предоставляет ряд опций командной строки для более гибкого управления запуском тестов:

- **Список доступных тестов**:

```shell
  bazel run //<путь_до_таргета> -- --list-tests
```

- **Запуск тестов по имени или тегу**:

```shell
  bazel run //<путь_до_таргета> -- --test-case "ИмяИлиТег"
```

**Примеры:**

*Запуск конкретного теста по имени:*

```shell
bazel run //<путь_до_таргета> -- "МойКонкретныйТест"
```

*Запуск тестов с определенным тегом:*

```shell
bazel run //<путь_до_таргета> -- "[mytag]"
```

*Комбинирование имени и тега:*

```shell
bazel run //<путь_до_таргета> -- "My*Test" "[mytag]"
```

**Итого**, чтобы запустить только нужный вам тест в Catch2:

- Используйте имя теста или шаблон имени в командной строке.
- Присвойте вашим тестам теги и используйте их для фильтрации при запуске.
- Комбинируйте фильтры по имени и тегам для более точного выбора тестов.

**Примечание:** Убедитесь, что вы компилируете тесты с использованием Catch2 версии 3.x или соответствующей версии, и что вы вызываете правильный исполняемый файл тестов.
