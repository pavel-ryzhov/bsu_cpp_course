# Точная сумма

Реализуйте функцию `AccurateSum(data)`, которая находит $\sum_{i=0}^{N-1} data[i]$.

Ваше решение должно быть точнее наивного, которое не проходит простые тесты. Напишите свой тест, на
котором проверьте различные варианты. Попытайтесь придумать решение, которое будет максимально точно
складывать эти числа.

Гарантируется, что размер вектора в приватных тестах не превосходят $`10^6`$. Чтобы пройти приватные
тесты нужно по точности сравняться или обогнать авторское решение.

__Эта задача с закрытыми тестами__ Код нужно протестировать самостоятельно.

### Примечания
* В этой задаче закрытые тесты.
* если вы написали решение с дополнительной памятью, подумайте, как обойтись без неё. Существует и
  решение за $O(1)$ по памяти.
* https://en.cppreference.com/w/cpp/io/manip/setprecision -- для вывода числа в консоль
* https://en.wikipedia.org/wiki/IEEE_754
* https://www.tuhh.de/ti3/paper/rump/OgRuOi05.pdf -- в статье подробно рассказывается с
  доказательством, как точно складывать/умножать вещественные числа.
