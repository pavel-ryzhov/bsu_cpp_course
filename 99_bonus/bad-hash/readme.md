# Bad Hash

Это задача типа [crashme](../../docs/crash_readme.md).

Исходный код находится в файле `run.cpp` и запускается в папке с задачей с помощью команды:
```sh
$ bazel run :bad_hash --config=asan
```

**ВАЖНО! Версия g++ 13, Linux**

Вам нужно заполнить файл `input.txt`, который используется в `run.cpp`. Изменения в любых других файлах не будут использоваться при проверке.

Вы также должны отправить генератор, который вы использовали для получения решения.
Для этого пишите код генератора в файле `solution/main.cpp`.
